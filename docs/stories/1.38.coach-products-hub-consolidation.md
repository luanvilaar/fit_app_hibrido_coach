# Story 1.38 — Consolidação do hub de produtos do coach

Status: Ready for Review

## Story

**As a** coach FitBlock,
**I want** usar uma única entrada para criar e editar programas,
**so that** o catálogo de produtos não duplique o editor, o calendário e as regras de persistência.

## Critérios de aceitação

1. `/app/coach/produtos` funciona como hub de catálogo: lista produtos, vendas, entregas e moderação sem renderizar editor de produto, formulário de programa, calendário ou compositor de sessão.
2. A ação de criar abre `/app/coach/produtos/novo` e a ação de editar/abrir um produto abre `/app/coach/produtos/[productId]`.
3. O hub não carrega templates de sessão, catálogo de exercícios ou dados necessários somente para o antigo editor inline.
4. Exclusão, submissão para análise, entrega de programa e moderação continuam funcionais e com seus estados de erro/carregamento.
5. Nenhuma regra de backend, migration, contrato, persistência, auto-save ou rota dedicada de dia é alterada.
6. Testes comprovam ausência do editor no hub, navegação para criação/edição e regressão das ações restantes; lint, typecheck, testes e build passam.

## Fora de escopo

- Redesenhar o workspace de criação ou edição dedicado.
- Alterar dados, autorização, contratos de repositório ou banco.
- Mudar URLs públicas, exceto a navegação interna para as rotas existentes.
