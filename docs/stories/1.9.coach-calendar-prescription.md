# Story 1.9 — Prescrição de treino no calendário do coach

Status: Ready for Review

## Objetivo

Permitir que um coach crie uma sessão com prescrição e publique essa sessão no calendário de uma equipe em uma única operação.

## Fonte de requisitos

- `FITBLOCK-APP-BLUEPRINT.md` — calendário, editor de sessão, publicação e equipes.
- Story 1.4 — backend de equipes, templates e prescrição.
- Story 1.8 — leitura do calendário do atleta.

## Critérios de aceitação

- [ ] O coach consegue visualizar as equipes nas quais está associado como coach.
- [ ] O coach consegue informar equipe, data, título, bloco, exercício e prescrição.
- [ ] A confirmação persiste o template e cria uma sessão publicada no calendário em uma transação.
- [ ] A sessão publicada aparece no calendário do coach e pode ser lida pelo atleta da equipe.
- [ ] Usuários que não são coach da equipe não conseguem criar ou listar a programação dela.
- [ ] Testes cobrem o contrato RPC e a transformação do formulário em payload de prescrição.

## Tasks / Subtasks

- [x] Criar RPCs protegidas para listar equipes/calendário do coach.
- [x] Criar operação transacional de template + prescrição + instância publicada.
- [x] Implementar repositório TypeScript para o fluxo do coach.
- [x] Implementar tela `/app/coach/calendario` com formulário e visão mensal.
- [x] Cobrir payload, repository e regressão com os gates do projeto.
