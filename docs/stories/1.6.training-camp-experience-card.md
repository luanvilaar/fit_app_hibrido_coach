# Story 1.6 — Training Camp Experience Card

Status: Ready for Review

## Objetivo

Publicar na home a experiência oficial do FitBlock Training Camp, com destino para as inscrições no WOD Arena e estrutura pronta para atualizar o status do evento sem alterar o componente.

## Fonte de verdade

- `fitblock_training_camp_card_implementation.md`
- [Página de inscrições no WOD Arena](https://www.wodarena.com.br/event/evt-org-1-training-camp-fitblock-mri7wxfh-647720)

## Critérios atendidos

- [x] Card com `01`, `CAMP`, `FitBlock Training Camp`, `29 AGO 2026` e `PulseFit · João Pessoa`.
- [x] Status centralizado e mapeado para `open`, `last_spots`, `closed`, `interest` e `completed`.
- [x] Card inteiro acionável, com papel de link, label acessível e foco visível no teclado.
- [x] Destino externo abre com `_blank`, `noopener` e `noreferrer` na web.
- [x] Mobile usa carrossel horizontal com snap; desktop usa composição card + manifesto.
- [x] Eventos de analytics preparados para visualização, clique, redirecionamento e Training Camp.
- [x] Dados fictícios anteriores foram removidos.
