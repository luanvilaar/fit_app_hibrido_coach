# Story 1.8 — Backend do calendário do atleta

Status: Ready for Review

## Objetivo

Disponibilizar no Supabase o calendário de sessões publicadas e o snapshot da prescrição para que o atleta consiga consultar o treino aplicado ao seu grupo.

## Fonte de requisitos

- `FITBLOCK-APP-BLUEPRINT.md` — calendário, publicação e biblioteca de sessões.
- Story 1.4 — backend de equipes, templates e instâncias.

## Critérios atendidos

- [x] `session_instances` ganha estado de execução separado do status de publicação.
- [x] Sessões em rascunho não são retornadas pela função de calendário do atleta.
- [x] Leitura do calendário valida vínculo do usuário com a equipe via RLS e `auth.uid()`.
- [x] Detalhe da sessão retorna o snapshot editável com blocos, exercícios e prescrições.
- [x] Repositório TypeScript encapsula listagem por intervalo e detalhe da sessão.
- [x] Tela de calendário consome o backend e mostra a prescrição aplicada.
- [x] Rollback remove funções, policies, índice, coluna e enum na ordem segura.
