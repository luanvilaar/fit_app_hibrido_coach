# Story 1.7 — Auth Visual Reference Alignment

Status: Ready for Review

## Objetivo

Alinhar as telas de login, criação de conta e recuperação de senha à referência visual enviada: viewport grafite, atmosfera teal escura e formulário branco compacto sobreposto no lado direito.

## Critérios atendidos

- [x] Visual teal ocupa toda a viewport e não interfere na interação do formulário.
- [x] Card branco compacto alinhado à direita no desktop.
- [x] Composição equivalente no mobile, mantendo o card sobre o visual.
- [x] Campos, mensagens, validações, recuperação e navegação Supabase preservados.
- [x] CTA e campos receberam o tratamento de borda, raio e contraste da referência.
- [x] Tokens específicos de autenticação foram adicionados ao design system.
